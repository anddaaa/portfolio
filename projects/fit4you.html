Fit4you

group project web development
built with: HTML CSS JavaScript
software: Visual Studio Code

Developed as a group project, this website was built to support anyone's fitness journey. Explore everything from exercise tutorials and custom routines to health advice, a small shop, and a personal trainer service, all in one fully interactive prototype.

Try it yourself

Feel free to explore! You can navigate through the entire website, browse sections, and test out the features through this interactive preview.

the idea

One website that looks after the whole routine: how to train, what to eat, how to relax and what to buy.

how it was made

HTML for the structure, CSS for the look and JavaScript for the interactive parts, written in Visual Studio Code.

the result

A multi-page site with a shared menu, exercise tutorials, training plans, a shop and contact forms.
